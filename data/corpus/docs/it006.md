## VPN Access Form

VPN can be used when using certain applications/websites when working remote and you need to be on a UT network. VPN does this for you. It is a Virtual Private Network that connects you to the UT network which will let you access applications such as EPIC. Fill out the form by clicking on the link below to get access to VPN.

**VPN Request for Faculty and Staff**Before requesting VPN access, please consider the alternate methods for accessing
UT resources.

To request VPN access for **faculty or staff**, please complete the VPN Request Form below.  The form below is **NOT** to be used for vendors.
